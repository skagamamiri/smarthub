# SMART HUB V1
Pusat Pembelajaran Digital SK Agama (MIS) Miri.

## Kandungan
- index.html — portal utama
- manifest.json + sw.js — asas PWA Android
- smart-hub-logo.png — logo rasmi yang dikunci
- supabase_schema.sql — struktur database

## Supabase
Buka index.html dan isi CONFIG.SUPABASE_URL serta CONFIG.SUPABASE_ANON_KEY.
Kemudian jalankan supabase_schema.sql dalam SQL Editor Supabase.

V1 sengaja menggunakan data contoh jika database belum disambungkan.
